# 👕 Product Page UI (HTML + CSS)

A modern **e-commerce product page UI** inspired by fashion retail websites like Pull&Bear.
Built using **HTML and CSS**, this project focuses on layout design, product presentation, and clean UI structure.

---

## 🚀 Features

* 🖼️ Product image gallery (multiple preview frames)
* 🎯 Main product display section
* 🏷️ Product title, price, and description
* 📏 Size selection dropdown UI
* 🛒 Add to Cart button
* ⬅️➡️ Navigation buttons (Prev / Next)
* 🎨 Clean and minimal design layout

---

## 🧠 Concepts Used

* HTML5 Layout Structuring
* CSS Flexbox for layout design
* Positioning (relative, alignment)
* UI Component Design
* Font Awesome Icons
* Responsive layout basics
